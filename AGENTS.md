# Instrucciones del proyecto

Este proyecto usa Gentle AI con el flujo ODD. La guía administrada por Gentle AI está en `.codex/AGENTS.md`. Antes de trabajar en una solicitud de este proyecto, lee esa guía, en especial las secciones de ODD e Implementation Routing, y sigue sus instrucciones aplicables.

Para solicitudes de exploración o planificación, inspecciona el proyecto y conversa sobre el alcance antes de modificar archivos. Para cambios autorizados, revisa primero el estado actual. Si el trabajo es sustancial, crea y mantén `odd/tasks/<nombre-de-la-tarea>.md` antes de editar el código; define alcance, criterios de aceptación, tareas y evidencia de verificación. Avanza una tarea a la vez y registra las decisiones en Engram cuando esté disponible.

No publiques cambios ni abras o fusiones una solicitud de incorporación sin autorización del usuario.
